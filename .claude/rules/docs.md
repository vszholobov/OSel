# Документация OSel

- Правила — `docs/guides/writing-docs.md`: у каждого факта один дом, шаблоны страниц, ссылки на код путём от корня без номеров строк, явные якоря `{#id}` на заголовках, на которые ссылаются.
- Новая страница — сразу в `docs/toc.yaml`, иначе её не будет на сайте и `cargo docs-check` упадёт.
- После правок — `cargo docs-check`. Сайт локально не собирать: это делает CI (`.github/workflows/docs.yml`), сборка падает на ссылках на несуществующие страницы, а битые якоря ловит `cargo docs-check`.
- Новая проверка в `tools/docs-check/tests/drift.rs` должна называть, чего не хватает и на какой странице.
