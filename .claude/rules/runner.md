# runner

- Runner — программа для хоста: собирает образ диска из ядра и запускает QEMU (`docs/architecture/testing.md`).
- Каждая функция с логикой — с unit-тестом, проверка — `cargo test-runner`.
- Новая переменная окружения: документ-комментарий в начале `runner/src/main.rs`, строка в `docs/reference/runner.md`, тест разбора значения.
- Тест ядра считается пройденным только по коду выхода 33 и полному числу строк `[ok]`; не ослаблять эту проверку.
