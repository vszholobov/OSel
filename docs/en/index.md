# OSel

![OSel logo: a donkey wearing a visor with a command line](../images/osel-logo.svg =160x160)

OSel is an educational Rust operating system for x86_64. It boots through UEFI and BIOS; the shell and single-player Go Tetris work in QEMU. Verification on real hardware continues.

## User documentation {#user}

[User documentation](user/index.md): ready-made images, QEMU and USB boot, game controls, hardware and crash reports.

## Developer documentation {#developer}

[Developer documentation](developer/index.md): building, testing, architecture, reference, our decisions and plans.

Repository: [OSel](https://github.com/vszholobov/OSel). Ready-made images: [releases](https://github.com/vszholobov/OSel/releases). Documentation describes the current `master`; changes are recorded in `CHANGELOG.md`. Agent instructions are in `AGENTS.md` at the repository root.
