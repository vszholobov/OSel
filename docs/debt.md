# Техдолг

**Для кого:** для тех, кто выбирает, что улучшить, или натыкается на странное ограничение.

**Коротко:** здесь каждое отложенное решение — одна строка: что отложено, почему и где подробности. Подробности живут на странице подсистемы, здесь только ссылка. Сделанный пункт удаляется.

| Что | Почему отложено | Где |
|---|---|---|
| Теневой буфер для прокрутки консоли | прокрутка читает весь экран из видеопамяти, на реальном железе это медленно; в QEMU не заметно | [консоль](architecture/drivers/console.md) |
| Backspace на предыдущую строку | решится вместе с терминалом этапа 3 | [консоль](architecture/drivers/console.md) |
| Отдельные стеки для #GP | осторожно: page fault на отдельный стек переносить нельзя, ему понадобится вложенность | [прерывания](architecture/core/interrupts.md) |
| Проверки `cargo fmt` и clippy в CI | включение форматирования переформатирует весь код, отдельный PR | [тулчейн и CI](guides/toolchain-and-ci.md) |
| KVM в CI | быстрее, но меняет поведение таймера; нужна хотя бы одна задача без KVM | [тулчейн и CI](guides/toolchain-and-ci.md) |
| Фильтр тестов `cargo test -- <фильтр>` | runner игнорирует аргументы тестов; один бинарник — `cargo test --test <имя>` | [тесты](guides/testing.md) |
| Освобождение физических страниц | аллокатор только выдаёт страницы; нужно для этапа 2 | [память](architecture/core/memory.md), [этап 2](design/stage-2-user-mode.md) |
| Куча фиксирована, 1 МБ | хватает этапу 1; для этапа 2 поднять до ~16 МБ | [память](architecture/core/memory.md) |
| `map_range` не откатывает частичное отображение | при ошибке уже отображённые страницы остаются | [память](architecture/core/memory.md) |
| Драйвер часов реального времени | нужен для `clock_gettime`; тесты форматов из курса ШАДа ждут его | [этап 2](design/stage-2-user-mode.md), [курс ШАДа](nikka.md) |
| Скрипт записи образа на флешку | отложен до проверки на ноутбуке, пока вручную | [флешка](start/usb.md) |
| Проверка на ноутбуке | нужен владелец с флешкой и машиной | [план](roadmap.md) |
