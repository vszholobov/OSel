# 0005. ABI Linux для запуска программ на Go

**Для кого:** для тех, кто проектирует системные вызовы и пользовательский режим.

**Коротко:** цель проекта — запустить консольный тетрис на Go. Go-программа собирается как обычная программа для Linux (`GOOS=linux GOARCH=amd64 CGO_ENABLED=0`), а ядро реализует системные вызовы Linux с теми же номерами и соглашениями, в объёме, нужном рантайму Go. Неподдержанные вызовы возвращают `ENOSYS`.

**Статус:** принято. **Дата:** 2026-10-11.

## Контекст

Рантайм Go обращается к ядру напрямую через системные вызовы, без libc. Статический бинарник под Linux не зависит ни от чего, кроме ядра. Курс ШАДа Nikka использует свой интерфейс системных вызовов в духе экзоядра, с `fork` в пространстве пользователя.

## Решение

- Номера, регистры и семантика системных вызовов — как в Linux x86_64.
- Стартовый стек процесса — по System V ABI: argv, envp, auxv.
- Реализуется подмножество, которое нужно Go и тетрису; план — в [проектировании этапа 2](../design/stage-2-user-mode.md).

## Рассмотренные альтернативы

- **Свой интерфейс, как в Nikka.** Отвергнуто: пришлось бы портировать рантайм Go на новую ОС.
- **Программы на Rust под свой интерфейс.** Отвергнуто: цель — существующий тетрис на Go.

## Последствия

- Многие решения диктует рантайм Go: потоки через `clone`, `futex`, `arch_prctl` для TLS, `epoll` для таймеров.
- Для проверки совместимости можно сверяться с man-страницами Linux и списком вызовов gVisor.
