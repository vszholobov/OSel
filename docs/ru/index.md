# OSel

![Логотип OSel: осёл в визоре с командной строкой](../images/osel-logo.svg =160x160)

OSel — учебная операционная система на Rust для x86_64. Загружается через UEFI и BIOS; в QEMU работают оболочка и одиночный тетрис на Go. Проверки на настоящем оборудовании продолжаются.
