# Wi-Fi на Acer

**Для кого:** разработчик следующего сетевого этапа.

**Коротко:** целевая карта — QCA6174 PCI `168c:003e`, subsystem `11ad:0807`, rev `32`. Первый проверяемый результат — диагностический образ с ROM-пробником. Для готового Wi-Fi нужны загрузка прошивки, сканирование, ассоциация WPA2 и обмен пакетами; эти пункты ещё открыты.

## Этапы {#stages}

1. **PCI и ROM.** Встроенные неизменённые файлы и точная плата, ограниченные D0/wake/reset/CE/BMI, сохранённый отчёт. Код написан; нужен результат `wifi probe` и `wifi regs` на Acer, чтобы проверить регистры, target version и обмен DMA. QEMU этот путь не проверяет.
2. **Прошивка.** BMI host-interest, PLL, OTP/калибровка, загрузка образа, конфигурация всех CE, BMI_DONE. HTC ready и WMI service-ready должны подтверждать запуск; тайм-аут сохраняет этап и возвращает ресурсы. До этих событий firmware running не выставляется.
3. **Сети.** WMI TLV, каналы 2,4 ГГц, scan events, BSSID/SSID/канал/RSSI. Парсер 802.11 и RSN проверяет длины. Начальная цель — видимый SSID и WPA2-Personal с CCMP, без WPA3/Enterprise/роуминга. Регион и доступные каналы нельзя угадывать по PCI ID.
4. **Подключение.** Аутентификация/ассоциация, EAPOL 4-way handshake, replay/MIC, установка PTK/GTK; пароль вводится отдельно без эха, не хранится в репозитории и не попадает в диагностический отчёт. Источник nonce должен давать достаточную случайность, а не только PIT или MAC.
5. **Данные.** HTT RX/TX и перевод кадров в существующий Ethernet-интерфейс smoltcp. После ассоциации — DHCP, маршрут, DNS, `ping gateway`, подключение тетриса. Потеря связи отменяет конфигурацию и соединения; смена адаптера не сохраняет старые SocketHandle.
6. **Готовность.** Повторные подключение/отключение и ошибочный пароль не оставляют утечек; проходящие UEFI/BIOS и существующий Ethernet. На Acer подтверждаются DHCP, ping и два игрока с локальным сервером. Публичный сервер проверяется после его запуска владельцем.

## Аппаратная проверка {#hardware}

Команды и сбор отчёта — [диагностика](../../user/diagnostics.md#report). До проверки ROM не объявляем работающий Wi-Fi. PR остаётся черновиком аппаратного этапа: наличие прошивки и зелёный CI не закрывают подключение.
