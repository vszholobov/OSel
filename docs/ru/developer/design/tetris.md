# Тетрис на Go

**Для кого:** для тех, кто работает над игрой и будущим сетевым этапом.

**Коротко:** одиночный режим добавлен в [PR №16 репозитория Tetris](https://github.com/vszholobov/Tetris/pull/16); устройство, запуск, сохранённый вызов внешней `clear` и проверки OSel описаны в [тетрисе](../architecture/tetris.md). Ниже остаётся план сетевого режима.

## Сетевой вариант (этап 4)

- Клиент подключается по `ws://` и `http://`, без TLS: нужен только TCP.
- Адрес сервера можно прописать в `/etc/hosts` внутри ramdisk: тогда Go не пойдёт к DNS и не нужен UDP.
- Websocket и HTTP Go делает сам, ядро передаёт байты.
- Нужны: перебор устройств PCI, драйвер сетевой карты (сначала Intel `e1000e` в QEMU), стек smoltcp, сокеты и полноценный `epoll`.

**Почему без Wi-Fi.** У каждой Wi-Fi-карты свой сложный драйвер (у Intel в Linux больше 100 тысяч строк), закрытая прошивка, которую драйвер загружает в карту, и отдельный протокол подключения и шифрования (WPA2/WPA3). Это больше всей остальной системы. Проводная карта на порядок проще: драйвер около тысячи строк и открытая документация. Какая карта стоит в машине, видно в Диспетчере устройств Windows (раздел «Сетевые адаптеры»); машины описаны в [справочнике](../../user/hardware/samsung-np530u4b.md).
