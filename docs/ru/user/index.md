# Пользователю

Язык: [Русский](index.md) · [English](../../en/user/index.md)

**Для кого:** для тех, кто хочет запустить OSel и поиграть в тетрис.

**Коротко:** скачайте готовый образ, загрузите его в QEMU или с флешки и введите `tetris` в оболочке. Собирать ядро и устанавливать Rust или Go для этого не нужно.

## С чего начать {#start}

- [Быстрый старт](quickstart.md) — готовые образы, оболочка и управление игрой.
- [Запуск с флешки](usb.md) — выбор образа, проверка суммы и запись носителя.
- [Красный экран](crash-report.md) — какие сведения приложить к сообщению о сбое.

## Оборудование {#hardware}

- [Samsung NP530U4B](hardware/samsung-np530u4b.md).
