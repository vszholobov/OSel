# Сетевой тетрис

**Для кого:** пользователи сетевого этапа OSel.

**Коротко:** одиночный `tetris` работает как раньше. Для игры по сети нужны работающий сервер и поддерживаемая Ethernet-карта. В этой версии проверена Intel 82574L в QEMU; работа сети на компьютере владельца пока не подтверждена.

## Подготовить сервер {#server}

Публичный сервер сейчас выключен. Можно запустить сервер из репозитория Tetris на другом компьютере с уже установленным Go:

```shell
cd apps/tetris/server
go run . -addr 0.0.0.0:8080
```

Для гостя QEMU сервер на хосте доступен как `10.0.2.2:8080`. Для настоящего компьютера OSel используйте IPv4-адрес машины с сервером в той же сети. Сервер принимает HTTP и WebSocket без TLS.

## Проверить сеть {#adapter}

Введите `net` в оболочке: выводятся карта, состояние линии, адрес и счётчики пакетов. Адрес получается через DHCP. На реальном компьютере поддерживается только Intel 82574L (`8086:10d3`), нужен Ethernet-кабель. Wi-Fi, USB Ethernet и другие модели карт пока не работают.

Для готового BIOS-образа в QEMU явно подключите карту:

```shell
qemu-system-x86_64 -drive format=raw,file=OSel.bios.img -serial stdio -no-reboot -netdev user,id=net0 -device e1000e,netdev=net0
```

При сборке через `cargo run` runner добавляет её сам. Используйте образ с сетевым этапом: выпуск 0.1.0 сети ещё не содержит.

## Играть {#play}

```text
tetris --network --server 10.0.2.2:8080
```

В меню `c` создаёт сессию, `r` обновляет список, `w`/`s` выбирают сессию, Enter подключает. Второй игрок должен подключиться к той же сессии. Можно сразу создать или присоединиться:

```text
tetris --network --server 10.0.2.2:8080 --create
tetris --network --server 10.0.2.2:8080 --session 123456789
```

Управление: `a`/`d` — движение, `s` — вниз, `q`/`e` — поворот. `x`, Escape или Ctrl+C выходят в оболочку. Оба поля помещаются в терминале на 80 символов.

## Если не подключается {#errors}

При выключенном сервере игра сообщает ошибку и возвращается в оболочку. Проверьте адрес, порт 8080, запущенный сервер и доступность TCP-порта из сети. Если `net` не показывает карту, нужен другой драйвер. Если карта есть, но адреса нет, проверьте кабель и DHCP. Укажите числовой IPv4: DNS пока нет. Для имени положите его адрес в `/etc/hosts` ramdisk перед сборкой.
