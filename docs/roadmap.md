# План

**Для кого:** для всех, кто хочет знать, что уже сделано и что дальше.

**Коротко:** цель — запустить на OSel консольный [тетрис на Go](https://github.com/vszholobov/Tetris), сначала в QEMU, потом на ноутбуке с флешки. Go-программа собирается как обычная программа для Linux, ядро реализует нужные ей системные вызовы Linux ([решение 0005](decisions/0005-linux-abi-for-go.md)). Сетевая игра — по желанию, отдельным этапом. Разработка и отладка идут в QEMU, ноутбук включается на контрольных точках.

Пока этап в работе, его подробности лежат в `design/`. PR, который закрывает этап, переносит их в описание устройства и решения ([правило](guides/writing-docs.md#single-home)).

## Этап 1. Ядро — сделан в коде, осталась проверка на ноутбуке {#stage-1}

- [x] Загрузка через `bootloader` 0.11 в режимах UEFI и BIOS, вывод текста в framebuffer ([решение 0001](decisions/0001-bootloader-0.11-and-uefi.md)).
- [x] Аппаратные прерывания: таймер 100 Гц, клавиатура PS/2, `hlt` вместо пустого цикла ([прерывания](architecture/core/interrupts.md), [клавиатура](architecture/drivers/keyboard.md)).
- [x] Страничная память и куча; ядро в верхней половине адресов ([память](architecture/core/memory.md), [решение 0006](decisions/0006-higher-half-kernel.md)).
- [x] Экран паники с адресом и регистрами, обработчики всех исключений процессора.
- [x] Блокировки, которые сами выключают прерывания и сообщают о взаимоблокировке ([блокировки](architecture/core/locking.md)).
- [x] Тесты на хосте, в QEMU и в CI, проверка утечек кучи ([как устроены тесты](architecture/testing.md)).
- [x] Сверка с блогом Phil Opp и курсом ШАДа ([курс](nikka.md)).
- [ ] Скрипт записи образа на флешку — отложен, пока запись описана вручную на странице [«Запуск с флешки»](start/usb.md).
- [ ] **Проверка на ноутбуке:** ядро загружается на [Samsung NP530U4B](reference/hardware/samsung-np530u4b.md) с флешки и печатает нажатые клавиши.

## Этап 2. Запуск программ {#stage-2}

Подробности и порядок работы — [проектирование этапа 2](design/stage-2-user-mode.md).

- [x] Ramdisk: архив cpio из папки `ramdisk/`, интерфейсы блочного устройства и файловой системы, ошибки Linux ([файлы и ramdisk](architecture/core/fs.md), [решение 0007](decisions/0007-storage-interfaces.md)).
- [x] Освобождение физических страниц, проверка утечек страниц в тестах ([память](architecture/core/memory.md#frames), [решение 0008](decisions/0008-frame-pool.md)).
- [x] Адресное пространство программы ([память](architecture/core/memory.md#address-spaces), [решение 0009](decisions/0009-shared-kernel-half.md)).
- [ ] Пользовательский режим: сегменты кольца 3 в GDT, стек ядра в TSS, исключения программы не роняют ядро.
- [ ] Загрузка ELF из ramdisk, стартовый стек с argv, envp и auxv; вход через `syscall`/`sysret`.
- [ ] Системные вызовы `write` и `exit`. **Проверка:** программа на ассемблере печатает «hello».
- [ ] SSE для пользовательских программ.
- [ ] Потоки и планировщик с вытеснением по таймеру, `clone`, `futex`.
- [ ] Системные вызовы Linux для рантайма Go (около 30). **Проверка:** Go-программа «hello world».
- [ ] Таймеры и упрощённое ожидание событий. **Проверка:** Go-программа с горутинами и `time.Sleep`.

## Этап 3. Тетрис {#stage-3}

Подробности — [разбор тетриса](design/tetris.md).

В репозитории тетриса:

- [ ] Одиночный режим.
- [ ] Очистка экрана управляющей последовательностью вместо программы `clear`.

В ядре:

- [ ] `/dev/tty`: открытие по пути, режимы терминала через `ioctl`, ввод через последовательный порт.
- [ ] Тетрис в ramdisk, запуск при старте ядра. **Проверка:** тетрис играется в QEMU.
- [ ] Автотест в CI: нажатия через последовательный порт, проверка вывода.
- [ ] Для реального экрана: управляющие последовательности в консоли и шрифт с кириллицей.
- [ ] Ввод с клавиатуры ноутбука в `/dev/tty`.

**Проверка на ноутбуке:** тетрис на Samsung с флешки.

## Этап 4 (по желанию). Сеть и современное железо {#stage-4}

Подробности — раздел «Сетевой вариант» в [разборе тетриса](design/tetris.md).

- [ ] Перебор устройств на шине PCI, поиск сетевой карты.
- [ ] Драйвер сетевой карты: сначала Intel `e1000e` в QEMU, потом карта ноутбука.
- [ ] Сетевой стек на smoltcp: DHCP, TCP.
- [ ] Сокеты и полноценный `epoll`.
- [ ] `/etc/hosts` в ramdisk с адресом сервера тетриса. **Проверка:** сетевой тетрис против настоящего сервера.
- [ ] Запуск на [Acer Nitro](reference/hardware/acer-nitro.md) через UEFI.
