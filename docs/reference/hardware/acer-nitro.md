# Acer Nitro

**Для кого:** для тех, кто запускает OSel на ноутбуке Acer Nitro.

**Коротко:** современный ноутбук с загрузкой только через UEFI. Грузите образ `OSel.uefi.img`. Перед этим выключите Secure Boot, а если на Windows включено шифрование BitLocker, сначала сохраните ключ восстановления. Меню загрузки — F12, его нужно один раз включить в настройках.

{% note warning %}

На этом ноутбуке OSel ещё не запускали, точная модель неизвестна. Данные ниже — типичные для линейки Acer Nitro 5 и требуют проверки. Модель написана на наклейке снизу, например AN515-xx.

{% endnote %}

## Характеристики {#specs}

| | Значение | Проверено |
|---|---|---|
| Линейка | Acer Nitro (вероятно Nitro 5), Windows 10 | да, со слов владельца |
| Режим загрузки | UEFI; старого режима BIOS на новых моделях часто нет | нет |
| Secure Boot | включён | нет |
| Клавиатура | встроенная, вероятно подключена как PS/2; внешняя USB без старого режима BIOS работать не будет | нет |
| Сетевая карта | обычно Realtek или Killer | нет |

## Подготовка {#prepare}

### 1. BitLocker {#bitlocker}

{% note alert %}

Если на Windows включено шифрование BitLocker, после выключения Secure Boot Windows попросит ключ восстановления. Без него в Windows не попасть.

{% endnote %}

1. Проверьте шифрование: **Пуск** → **Параметры** → **Обновление и безопасность** → **Шифрование устройства** (или Панель управления → **Шифрование диска BitLocker**).
2. Если оно включено, сохраните ключ восстановления: он есть на [account.microsoft.com/devicekey](https://account.microsoft.com/devicekey) под вашей учётной записью Microsoft. Перепишите код или сфотографируйте его.

### 2. Настройки BIOS {#bios}

1. При включении нажимайте **F2**.
2. **Security** → **Set Supervisor Password**: задайте пароль. Без него пункт Secure Boot нельзя изменить. Пароль потом можно снять.
3. **Boot** → **Secure Boot** → **Disabled**.
4. **Main** → **F12 Boot Menu** → **Enabled**.
5. **F10** → **Yes**, чтобы сохранить и выйти.

## Загрузка {#boot}

1. Запишите `OSel.uefi.img` на флешку, см. [Запуск с флешки](../../start/usb.md).
2. Включите ноутбук и нажимайте **F12**.
3. Выберите флешку.

## Риски {#risks}

- Диск с Windows OSel не трогает: драйверов дисков в ядре нет, а встроенный диск таких ноутбуков (NVMe) ядро вообще не видит.
- Если ноутбук рабочий, начинайте проверки на [Samsung NP530U4B](samsung-np530u4b.md): там меньше настроек и нечего терять.
- При зависании удерживайте кнопку питания 5–10 секунд, выньте флешку и включите ноутбук снова.
