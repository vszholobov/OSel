# Samsung NP530U4B

**Для кого:** для тех, кто запускает OSel на этом ноутбуке.

**Коротко:** первая машина для проверки OSel на железе. Грузите образ `OSel.bios.img` в режиме BIOS (CSM). Один раз выключите в настройках BIOS Fast BIOS Mode, после этого флешка выбирается по F10.

{% note warning %}

На этом ноутбуке OSel ещё не запускали. Данные ниже собраны по описанию модели и требуют проверки. После первого запуска обновите эту страницу.

{% endnote %}

## Характеристики {#specs}

| | Значение | Проверено |
|---|---|---|
| Модель | Samsung Series 5 Ultra 14", NP530U4B, около 2012 года | да, со слов владельца |
| Установленная система | Windows 7 | да, со слов владельца |
| Процессор | Intel Core i3 или i5 второго поколения (Sandy Bridge), 64-битный | нет |
| Экран | 14", 1366×768, встроенная графика Intel HD 3000 | нет |
| Клавиатура | встроенная, подключена как PS/2 | нет |
| Сетевой разъём | вероятно, есть; модель сетевой карты неизвестна | нет |
| Режим загрузки | BIOS умеет и старый режим (CSM), и UEFI; Windows 7 почти наверняка стоит в старом режиме | нет |

Как проверить в Windows 7:

- разрядность и процессор: **Win+R** → `msinfo32` → «Тип системы» и «Процессор»;
- режим загрузки: **Win+R** → `diskmgmt.msc` → правый клик по «Диск 0» → **Свойства** → вкладка **Тома** → «Стиль раздела»: MBR означает BIOS, GPT — UEFI;
- сетевая карта: **Win+R** → `devmgmt.msc` → «Сетевые адаптеры».

## Подготовка BIOS {#bios}

1. При включении нажимайте **F2**, откроются настройки BIOS.
2. **Advanced** → **Fast BIOS Mode** → **Disabled**. Пока этот режим включён, ноутбук не видит флешки при загрузке.
3. **F10** → **Yes**, чтобы сохранить и выйти.

На Windows это не влияет, настройку можно вернуть обратно.

## Загрузка {#boot}

1. Запишите `OSel.bios.img` на флешку, см. [Запуск с флешки](../../start/usb.md).
2. Включите ноутбук и нажимайте **F10**, откроется меню загрузки.
3. Выберите флешку.

## Риски {#risks}

{% note alert %}

Не загружайте OSel на этом ноутбуке в режиме UEFI. Ноутбуки Samsung этих лет известны тем, что переставали включаться после записи в их память настроек UEFI. Сама OSel в эту память не пишет, но безопаснее грузиться в режиме BIOS.

{% endnote %}

- Диск с Windows OSel не трогает: драйверов дисков в ядре нет.
- При зависании удерживайте кнопку питания 5–10 секунд, выньте флешку и включите ноутбук снова.

## Как вернуть настройки {#restore}

Когда эксперименты закончены: **F2** → **Advanced** → **Fast BIOS Mode** → **Enabled** → **F10** → **Yes**. Как вернуть флешку к обычному использованию — в разделе [Как вернуть обычную систему](../../start/usb.md#recovery).
